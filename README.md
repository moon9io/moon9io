## 📖 عني | About Me

أهلاً بك في عالمي الرقمي! أنا **moon9io**، مطور شغوف بالتقنية ومتحمس لمشاريع المصادر المفتوحة. أستمتع بتحويل الأفكار إلى واقع ملموس من خلال الكود، مع التركيز على تجربة المستخدم والأداء. أؤمن بقوة التعلم المستمر والمساهمة في مجتمع المطورين.

**الاهتمامات:** 💻 تطوير الويب، 🌐 تقنيات جديدة، 🐧 أنظمة Linux، 🎮 الألعاب، 📚 القراءة، 🍵 تحضير الشاي.

## 🚀 أبرز المشاريع | Featured Projects

هنا بعض من أبرز أعمالي التي أفتخر بها:

### 🎮 Hangman Pro Game

[![Hangman Pro Game](https://github.com/moon9io/hangman-pro-game/blob/master/screenshot.png?raw=true)](https://moon9io.github.io/hangman-pro-game/)

لعبة المشنوق الكلاسيكية بتصميم حديث واحترافي، تدعم اللغتين العربية والإنجليزية، مع نظام نقاط وإنجازات متقدم، ومؤثرات صوتية ديناميكية. تم تطويرها باستخدام HTML5, CSS3, و Vanilla JavaScript.

- **المستودع:** [moon9io/hangman-pro-game](https://github.com/moon9io/hangman-pro-game)
- **اللعب المباشر:** [Hangman Pro Game Live](https://moon9io.github.io/hangman-pro-game/)

### 🍵 Tea House Blog

مدونة شخصية مبنية باستخدام Hugo، أشارك فيها أفكاري وتجاربي في عالم التقنية والحياة. تتميز بتصميم بسيط وأنيق يركز على المحتوى.

- **المستودع:** [moon9io/tea-house](https://github.com/moon9io/tea-house)
- **المدونة:** [Tea House](https://moon9io.github.io/tea-house/)

### 🎬 Linux Philosophy Motion Graphics

مشروع رسوم متحركة (Motion Graphics) يستكشف فلسفة نظام Linux والمصادر المفتوحة، يهدف إلى تقديم مفاهيم معقدة بطريقة بصرية جذابة ومبسطة.

- **المستودع:** [moon9io/linux-philosophy-motion-graphics](https://github.com/moon9io/linux-philosophy-motion-graphics)
